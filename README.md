# NullTroll

Simple troll-control plugin for Bukkit/Spigot/Paper servers.

## Features

- Block player movement
- Block camera rotation
- Block placing blocks
- Block breaking blocks
- Block interactions
- Block item drop and pickup
- Block chat
- Block damage
- Configurable messages

## Installation

1. Put `NullTroll.jar` into `/plugins`
2. Start the server
3. Configure `plugins/NullTroll/config.yml`

## Command

/troll <player> <parameter> <true/false>

Examples:

/troll Steve move true
/troll Steve camera true
/troll Steve place false
/troll Steve all true

## Parameters

move
camera
place
break
interact
drop
pickup
chat
